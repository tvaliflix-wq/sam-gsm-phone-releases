# SAM GSM PHONE — حزم التحديث

مستودع عام يحتوي **فقط** على حزم التحديث الموقّعة (`*.samupdate`) لبرنامج SAM GSM PHONE.

- لا يحتوي هذا المستودع على مصدر البرنامج ولا على مولّد المفاتيح.
- كل حزمة موقّعة؛ يرفضها البرنامج إذا عُدّل ملفها哪怕 حرفاً واحداً.
- بيانات المحل (`shop.db`) داخل الحزمة؟ **لا** — الحزمة تحمل برنامجاً جديداً فقط، وبياناتك تبقى على جهازك.

## تثبيت التحديث عند الزبون
1. افتح البرنامج ← الشريط الجانبي ← **تحديث البرنامج**.
2. الصق رابط التنزيل المباشر من صفحة الإصدار واضغط **تنزيل**، أو نزّل الملف يدوياً ثم اختر **استيراد حزمة**.
3. اضغط **تثبيت التحديث وإعادة التشغيل**.

تُحفظ نسخة احتياطية تلقائياً قبل التثبيت.
